# TasteLocal SG Asset Provenance

## 1. Purpose

This document records the origin and intended project context of the media, interface assets, and fictitious demonstration information included with TasteLocal SG.

## 2. Controlled Experience Images

The 20 WebP images under `frontend/public/demo-images/experiences/` were created specifically for the TasteLocal SG capstone and controlled portfolio demonstration.

They are not presented as photographs of real participating Vendors. They may be used with the TasteLocal SG project and portfolio presentation.

## 3. Hero Image

`frontend/src/assets/hero.png` was generated through an AI-assisted Codex workflow specifically for TasteLocal SG. It was not copied from an external website or third-party collection.

The image is currently retained as a project asset even though it is not used by the current interface.

## 4. Interface Icons

`frontend/public/favicon.svg` and `frontend/public/icons.svg` are retained project interface assets. Their inclusion does not claim ownership of any third-party brand.

## 5. Fictitious Project Information

Demonstration names, accounts, Vendors, records, and contact details are synthetic or fictitious.

`support@tastelocal.sg` is a fictitious project-branded address used for interface demonstration. It is not represented as a monitored operational support mailbox. The project does not claim ownership or control of the `tastelocal.sg` domain.

- Source code is covered by the MIT Licence.
